# chandranisaha.github.io

My portfolio: a molecule you can scroll through, poke and interview. Vite + Three.js, no framework.

- `source` branch: this code.
- `main` branch: the built site that GitHub Pages serves.

## Run

```
npm install
npm run dev
```

## Edit

All text, projects and the twin's answers live in `src/content.js`. Project screenshots are in `public/projects/`.

## Deploy

```
./deploy.sh "what changed"
```

This builds the site and pushes the result to `main`.
